Frequently Asked Questions

What is Megicula Stake?

Megicula Stake is a decentralized staking protocol built on OPN Testnet. Users stake MEGA tokens and earn continuous rewards at a configurable APY, currently set to 10%.

How are rewards calculated?

Rewards follow a continuous linear formula: reward = stakedAmount × APY_bps × duration / (365 days × 10,000). There's no compounding — rewards accrue proportionally to staked amount and time.

Is there a lock-up period?

No. You can unstake or claim rewards at any time. There is no minimum staking duration and no early withdrawal penalties.

What is MEGA?

MEGA (Megicula Token) is the ERC20 token used for staking. Total supply is 100,000,000 MEGA. It follows the standard ERC20 interface and is also burnable.

Is the code audited?

The contracts use OpenZeppelin battle-tested libraries (ReentrancyGuard, Pausable, SafeERC20, Ownable). The full codebase is open-source and available on GitHub for community review. Formal audit is on the roadmap.

What network do I need?

Add OPN Testnet to your wallet: Chain ID 984, RPC URL https://testnet-rpc.iopn.tech, Currency symbol OPN.
